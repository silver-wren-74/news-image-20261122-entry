## The image

`main.py` draws a one-page newspaper front page — "The World in One Page" —
in pure Python (standard library only, no network, deterministic). Eight
stories, all verified against reporting dated 22 November 2026:

1. **Baltic Sea** — drones set the Russian cargo ship Sparta II ablaze; it
   drifts into Finnish waters as Helsinki imposes air and sea curbs.
2. **COP31, Antalya** — climate talks still deadlocked, running into Sunday.
3. **Gulf** — tankers hit off Oman; Bahrain probes a Patriot crash amid
   reports of Iranian drone attacks.
4. **Washington** — Pentagon curbs US–Canada military ties.
5. **Copenhagen** — Denmark accuses Russia of an assassination plot.
6. **Kyiv** — Zelensky calls Putin a "killer" after Trump praises him.
7. **South Africa** — ANC fights to hold its cities as the country votes.
8. **Bihar, India** — Modi opens the Nitish Setu bridge as Cyclone Akvan
   disrupts flights.

Plus a tonight strip: the Las Vegas GP under the lights (Norris on pole)
and Australia ending England's seven-match T20 winning streak.

## Run it

```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.png
```

Two runs produce byte-identical output (1024×1024 PNG, ~23 KB).
